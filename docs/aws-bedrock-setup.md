# AWS Bedrock Setup Guide

This guide provides detailed instructions for setting up AWS Bedrock with Amazon Nova Pro for the AI-powered product search demo.

## Prerequisites

- AWS Account with appropriate permissions
- AWS CLI installed
- Python 3.10+ environment

## Step-by-Step Setup

### 1. Install AWS CLI

**macOS:**
```bash
brew install awscli
```

**Linux:**
```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
```

**Windows:**
Download and run the AWS CLI MSI installer from the [AWS documentation](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html).

### 2. Configure AWS Credentials

Choose one of the following methods:

#### Method A: AWS CLI Configuration (Recommended)
```bash
aws configure
```
Enter the following when prompted:
- AWS Access Key ID: `your-access-key-id`
- AWS Secret Access Key: `your-secret-access-key`
- Default region name: `us-east-1`
- Default output format: `json`

#### Method B: Environment Variables
```bash
export AWS_REGION="us-east-1"
export AWS_ACCESS_KEY_ID="your-access-key-id"
export AWS_SECRET_ACCESS_KEY="your-secret-access-key"
```

#### Method C: IAM Roles (For EC2 instances)
```bash
# Only set the region when using IAM roles
export AWS_REGION="us-east-1"
# AWS SDK will automatically use the instance's IAM role
```

### 3. Set Up IAM Permissions

Create an IAM policy with the following permissions:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "bedrock:InvokeModel",
                "bedrock:ListFoundationModels",
                "bedrock:GetFoundationModel"
            ],
            "Resource": [
                "arn:aws:bedrock:*::foundation-model/amazon.nova-pro-v1:0",
                "arn:aws:bedrock:*::foundation-model/amazon.titan-embed-text-v2:0"
            ]
        }
    ]
}
```

Attach this policy to your IAM user or role.

### 4. Verify Configuration

Test your AWS configuration:

```bash
# Test basic AWS connectivity
aws sts get-caller-identity

# Verify Bedrock access
aws bedrock list-foundation-models --region us-east-1

# Test specific model access
aws bedrock get-foundation-model --model-identifier amazon.nova-pro-v1:0 --region us-east-1
```

### 5. Supported Regions

AWS Bedrock with Nova Pro is available in:
- `us-east-1` (N. Virginia) - **Recommended**
- `us-west-2` (Oregon)
- `eu-west-1` (Ireland)

### 6. Environment Configuration

Create a `.env` file with:
```bash
AWS_REGION=us-east-1
# Optional if using IAM roles:
AWS_ACCESS_KEY_ID=your-access-key-id
AWS_SECRET_ACCESS_KEY=your-secret-access-key
```

### 7. Load Data with AWS Backend

```bash
# Load product and user data using AWS Bedrock embeddings
python3 load_data.py --aws-region us-east-1

# Optional: Flush existing data first
python3 load_data.py --aws-region us-east-1 --flush
```

### 8. Start the Application

```bash
flask run --host=0.0.0.0 --port=5001
```

## Model Information

### Amazon Nova Pro (Text Generation)
- **Model ID:** `amazon.nova-pro-v1:0`
- **Use Case:** Personalized product descriptions
- **Max Tokens:** 200 (configured in application)
- **Temperature:** 0.7
- **Top P:** 0.9

### Amazon Titan Text Embeddings v2 (Vector Embeddings)
- **Model ID:** `amazon.titan-embed-text-v2:0`
- **Vector Dimensions:** 1024
- **Use Case:** Product and user profile embeddings
- **Normalization:** Enabled

## Cost Considerations

AWS Bedrock pricing is based on:
- **Input tokens:** Text sent to the model
- **Output tokens:** Text generated by the model
- **Embedding requests:** Number of texts embedded

For current pricing, see the [AWS Bedrock Pricing page](https://aws.amazon.com/bedrock/pricing/).

## Troubleshooting

### Common Issues

**"NoCredentialsError: Unable to locate credentials"**
- Verify AWS CLI configuration: `aws configure list`
- Check environment variables are set correctly
- Ensure IAM user has programmatic access enabled

**"AccessDeniedException: User is not authorized"**
- Verify IAM permissions include `bedrock:InvokeModel`
- Check that you're using a supported region
- Ensure the models are available in your region

**"ValidationException: The model identifier is invalid"**
- Verify Nova Pro availability: `aws bedrock list-foundation-models --region us-east-1 | grep nova-pro`
- Check you're using the correct model ID: `amazon.nova-pro-v1:0`

**"ThrottlingException: Rate exceeded"**
- AWS Bedrock has rate limits
- The application includes automatic retry logic
- Consider requesting quota increases in AWS Console

### Performance Tips

1. **Choose the right region:** Use the region closest to your users
2. **Monitor usage:** Use AWS CloudWatch to track API calls and costs
3. **Cache responses:** The application caches AI responses for 2 hours
4. **Batch processing:** The data loading script processes embeddings efficiently

### Security Best Practices

1. **Use IAM roles** when possible instead of access keys
2. **Rotate access keys** regularly
3. **Use least privilege** IAM policies
4. **Monitor API usage** with CloudTrail
5. **Enable VPC endpoints** for enhanced security (optional)
